MT Maker → Xcode

This zip is an Xcode project. Maker wrote the game.
You still compile and sign in Xcode on a Mac — same as any other iOS app.

1. Unzip this folder.
2. Open MTMadeGame.xcodeproj in Xcode.
3. Signing & Capabilities → your Apple Team.
4. Run on a simulator or device.
5. Product → Archive → Distribute to App Store Connect.

The game is MTMadeGame/game.html.
Bundle id is au.com.futuret3ch.made — change it in the target’s Signing settings before you list.

Apple Developer Program ($99/year) is required to list on the App Store.
